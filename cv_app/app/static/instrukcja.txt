============================================================
INSTRUKCJA URUCHOMIENIA (POLSKI)
============================================================

Poniżej znajdują się kroki niezbędne do uruchomienia aplikacji znajdującej się w folderze 'cv_app'.

1. Sklonuj repozytorium (pobierz kod):
   Otwórz terminal (konsolę) i wpisz:
   git clone https://github.com/WiktorGap/AI_dev.git

2. Przejdź do odpowiedniego katalogu:
   Musisz wejść do folderu głównego, a następnie do folderu z aplikacją:
   cd AI_dev/cv_app

3. Utwórz wirtualne środowisko (venv):
   Upewnij się, że masz zainstalowanego Pythona. Wpisz:
   python -m venv venv

4. Aktywuj wirtualne środowisko:
   
   - Dla systemu Windows (Command Prompt):
     venv\Scripts\activate
     
   - Dla systemu Windows (PowerShell):
     .\venv\Scripts\Activate.ps1
     
   - Dla systemów macOS / Linux:
     source venv/bin/activate

   (Po poprawnej aktywacji powinieneś widzieć napis "(venv)" na początku linii w terminalu).

5. Zainstaluj wymagane biblioteki:
   pip install -r requirements.txt

6. Uruchom aplikację Flask:
   flask run

   Aplikacja powinna być teraz dostępna w przeglądarce pod adresem, który wyświetli się w terminalu (zazwyczaj http://127.0.0.1:5000).


============================================================
SETUP INSTRUCTIONS (ENGLISH)
============================================================

Below are the steps required to run the application located in the 'cv_app' folder.

1. Clone the repository (download the code):
   Open your terminal and run:
   git clone https://github.com/WiktorGap/AI_dev.git

2. Navigate to the project directory:
   Go into the main folder and then into the app folder:
   cd AI_dev/cv_app

3. Create a virtual environment (venv):
   Make sure you have Python installed. Run:
   python -m venv venv

4. Activate the virtual environment:

   - For Windows (Command Prompt):
     venv\Scripts\activate
     
   - For Windows (PowerShell):
     .\venv\Scripts\Activate.ps1
     
   - For macOS / Linux:
     source venv/bin/activate

   (After successful activation, you should see "(venv)" at the beginning of your terminal line).

5. Install dependencies:
   pip install -r requirements.txt

6. Run the Flask application:
   flask run

   The application should now be accessible in your web browser at the address shown in the terminal (usually http://127.0.0.1:5000).
